# China Import Cars — мобильное приложение (демо)

Интерактивный прототип мобильной версии сайта [chinaimportcars.ru](https://chinaimportcars.ru)
в формате приложения. Сделан для согласования с заказчиком.

**Живой предпросмотр:** откройте ссылку GitHub Pages на телефоне.

## Что внутри
- 📱 App-подход: нижнее таб-меню, плавные переходы между экранами, bottom-sheet заявки
- 🏠 **Главная** — hero-слайдер авто, быстрые действия, лидеры продаж, преимущества, шаги работы, отзывы, CTA
- 🚗 **Каталог** — поиск, фильтры (Электро / Гибрид / Бензин), карточки авто
- 📄 **Карточка авто** — фото, характеристики, «в стоимость входит», кнопка «Заказать»
- ⭐ **Отзывы** — реальные отзывы клиентов
- 📞 **Контакты** — телефон, Telegram, YouTube, форма обратного звонка

Сохранены фирменные цвета, контент и фотографии текущего сайта — улучшена только
подача и удобство под мобильные устройства.

## Статус
Демонстрационный прототип. Формы не отправляют данные (показывают экран успеха).
После одобрения — перенос улучшений в рабочую версию сайта.
